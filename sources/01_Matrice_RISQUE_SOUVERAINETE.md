# COMMENT LIRE CETTE MATRICE

## Risque fournisseur

Le **risque fournisseur** mesure la possibilité qu’un industriel rencontre des difficultés concernant :

* les délais ;
* les coûts ;
* la qualité ;
* les volumes ;
* la montée en cadence ;
* les approvisionnements ;
* le financement ;
* les compétences ;
* ou la continuité industrielle.

Échelle utilisée :

* **FAIBLE**
* **MODÉRÉ**
* **SIGNIFICATIF**
* **ÉLEVÉ**

## Criticité souveraine

La **criticité souveraine** mesure la difficulté pour la France de remplacer rapidement une capacité industrielle ou technologique.

Échelle utilisée :

* **IMPORTANTE**
* **TRÈS ÉLEVÉE**
* **CRITIQUE**

## Attention à l'interprétation

Une entreprise peut simultanément présenter :

* une situation financière solide ;
* un carnet de commandes très élevé ;
* et une forte criticité souveraine.

Une entreprise affichant un carnet très important peut également présenter un **risque de saturation industrielle**.

La lecture doit donc croiser :

**finance + carnet + capacité + supply chain + substituabilité + souveraineté.**
